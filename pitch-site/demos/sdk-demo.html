Three Integration Patterns

From zero to production in minutes. Choose the pattern that fits your architecture.

Drop-in Module
< 5 min Setup
Install the SDK, provide an API key, and call rank(). Interest graphs build automatically from usage.
// 1. Install // npm i @recome/sdk import { RecoMeSDK } from '@recome/sdk'; const sdk = new RecoMeSDK({ apiKey: 'rm_live_sk_...' }); const results = await sdk.rank({ userId: 'user_123', candidates: contentChunks });
Full Graph Sync
Real-time Sync
Stream user events directly into the interest graph. Rankings update live as new signals arrive from any surface.
// Stream events in real-time const stream = sdk.stream('user_123'); stream.on('event', (event) => { // Graph updates automatically console.log(event.graphDelta); }); // Emit user signals await stream.emit({ type: 'view', entity: 'FOLFIRINOX', duration: 142 });
Batch Processing
Offline Pipeline
Run bulk ranking jobs overnight. Ideal for digest emails, weekly reports, or large document corpora.
// Submit a batch job const job = await sdk.batch({ userIds: allUsers, corpus: weeklyReports, schedule: '0 6 * * 1' // Mon 6am }); // Poll or webhook on complete job.onComplete((results) => { // results[userId] = ranked[] sendDigestEmails(results); });
