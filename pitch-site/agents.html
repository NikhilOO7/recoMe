Architecture

The Brain Architecture

All 8 agents plug into a single cognitive substrate — no duplicate learning, no siloed preferences.

🧬 Smriti Memory System

Human-like memory with forgetting curves. Preferences decay unless reinforced — just like a real brain. Strong signals persist; weak ones fade naturally.

  • Context buckets: where you were, when it happened, why you engaged
  • Forgetting curves: stale preferences auto-decay unless reinforced
  • Pattern detection: recognizes behavioral clusters across time and platform
  • Episodic + semantic memory in a single unified store

🕸️ Knowledge Graph

Entity relationships with affinity propagation. Preferences aren't stored as flat lists — they're a weighted graph where blocking one node cascades to related nodes automatically.

  • Affinity propagation: block crypto → auto-blocks BTC, NFT, Ethereum
  • Cross-domain links: sneaker interest → streetwear → Jordan Brand events
  • Weighted edges that update with every interaction
  • Query interface for all 8 agents: query_knowledge_graph()
🔗

All 8 agents share this single brain — no duplicate learning. When ShopperAgent discovers you prefer GOAT over StockX, FilterAgent immediately uses that signal to surface GOAT-linked content. When ScoutAgent finds a research paper you engage with, AdvisorAgent's explanations get more precise. Every agent makes every other agent smarter.

Privacy Architecture

Privacy by Architecture,
Not Policy

GuardianAgent doesn't enforce a privacy policy. It enforces privacy structurally — at the code level, before data moves anywhere.

⛔

Literal Veto Power

GuardianAgent can halt any other agent mid-execution. It doesn't log violations — it stops them. If consent isn't confirmed before an external call, the call never happens.

💾

Local by Default

All user data lives in IndexedDB on the device. Nothing reaches a server unless the user explicitly approves that specific data type for that specific operation.

✅

Consent Per Operation

External calls aren't covered by a blanket "I agree." Each agent operation that touches external APIs requires its own consent record, stored and auditable.

📋

Complete Audit Trail

Every agent decision is logged locally: what ran, when, what data was accessed, what was blocked, and why. Users can inspect the full log at any time.

🔒

Zero Trust Between Agents

Agents don't trust each other. Every inter-agent data request passes through GuardianAgent. ShopperAgent cannot read SocialAgent's data without an explicit grant.

🧹

Right to Forget

Users can delete any preference node, any topic, or wipe the entire knowledge graph. Deletion cascades through all edge relationships immediately.

Why this matters in 2026

GDPR Enforcement CCPA EU AI Act UK DPDI Bill FTC AI Guidelines

GDPR enforcement, CCPA, and the EU AI Act all require provable privacy compliance — not a policy document. GuardianAgent makes compliance structural: auditable logs, consent-per-operation, local storage, and a veto layer that cannot be bypassed. Compliance isn't a checkbox — it's the architecture.

Risk Register

Critical Risks

We've identified three risks specific to the agent layer. Each has a structural mitigation, not just a plan.

💸
LLM API Cost Escalation

Agents that call external LLMs (AdvisorAgent, ScoutAgent explain mode) add per-call costs that scale with user count. At high volume, this compresses margins.

Mitigation: Most agents (FilterAgent, ShopperAgent, GuardianAgent) run entirely on local logic with no LLM calls. External LLM calls are opt-in, per-operation, and surfaced to users as a cost-incurring action. LLM calls are the exception, not the default.

🌀
Agent Hallucination in High-Stakes Contexts

ShopperAgent could misidentify a product SKU or recommend a counterfeit listing. ScoutAgent could surface a retracted paper. In both cases, acting on wrong information has real costs.

Mitigation: GuardianAgent review layer intercepts all external-action recommendations. Confidence thresholds are required before any agent surfaces an actionable recommendation — assess_deal() must return ≥0.70 to trigger a notification. Below-threshold results are silently discarded.

🧩
Complexity Tax — 8 Agents is Hard to Explain

Consumer marketing cannot lead with "8 specialized agents sharing a knowledge graph." The mental model is too technical and the onboarding drop-off risk is real.

Mitigation: Users never see "agents." They see "your AI assistant" and named features: Price Alerts, Research Digest, Smart Feed. The agent architecture is the implementation detail; the product language is outcomes. Internal complexity is invisible to the end user.
